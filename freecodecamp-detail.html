Free, self-paced coding education.

What it is

freeCodeCamp is a nonprofit offering thousands of hours of free coding lessons, organized into structured certification tracks, all in your browser.

What you can learn

Web development (HTML, CSS, JavaScript), Python, data analysis, machine learning basics, and more.

How to use it

Create a free account, pick a certification path, and work through interactive challenges at your own pace.

Good to know

Everything works in-browser, so no software install needed — useful if you're learning from a phone.
